# MuratovaLife v24 — «Эмоциональный ретрит»

На существующем маршруте `/material/quality-0` создана полноценная иллюстрированная самостоятельная программа на 7 дней.

- Вся страница оформлена как непрерывное акварельное путешествие с фоновыми пейзажами и образами из ранее подготовленной коллекции МАК. Не используются пустые блоки и отдельная стандартная карточка с одним предложением.
- 7 дней: «Остановиться», «Вернуться в тело», «Найти тихое место», «Отпустить лишнее», «Тёплый контакт», «Замечать живое», «Выбрать свою дорогу».
- Каждый день содержит короткую практику, вопрос для самостоятельного размышления, личную заметку и отметку о прохождении.
- Отметки и заметки сохраняются локально в браузере пользователя (`localStorage`), не передаются на сервер и не требуют регистрации. При очистке данных браузера исчезают.
- Верстка адаптивна для телефона, предусмотрены доступные подписи, кнопки и режим уменьшенной анимации.
- Заголовок, короткое описание, дополнительный текст и пользовательское изображение из CMS продолжают использоваться. Остальные страницы и их контент не изменены.
- Использованы имеющиеся локальные изображения акварельных МАК-мотивов, добавлены оптимизированные копии в `public/images/retreat/`.

## Важно перед обновлением

- **Не удалять и не пересоздавать** Docker volume `/app/data`. Рекомендуется сделать резервную копию содержимого тома перед публикацией.
- CMS, загруженные через админку изображения, статьи и данные в `/app/data` не меняются этим архивом.
- Приложение не содержит онлайн-оплаты и не сохраняет заметки пользователей на сервере.
- Полная сборка `npm run build` не проверена в текущей среде: `npm install` не завершился из-за отсутствия доступа к пакетному реестру. CSS и адаптивная компоновка проверены в Chromium на статическом предпросмотре; после развёртывания нужна проверка страницы в Next.js.
