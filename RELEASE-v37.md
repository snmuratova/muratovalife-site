# v37 — SEO
- На основе v36; дизайн и контент не изменены.
- robots.txt и динамический sitemap.xml из CMS; скрытые карточки, служебные страницы, дубли ссылок и отдельные тарифы исключены из sitemap.
- Индивидуальные title, description, canonical и Open Graph для публичных страниц, noindex для админки и нецелевых материалов.
- WebSite/Person JSON-LD на главной; без вымышленных отзывов, рейтингов или квалификаций.
- DNS-подтверждение предпочтительно; альтернативно переменные GOOGLE_SITE_VERIFICATION / YANDEX_VERIFICATION при сборке.
- После деплоя проверить /robots.txt и /sitemap.xml, добавить домен в Яндекс Вебмастер и Search Console, передать sitemap.xml.
- Индексация не гарантирует позиции. noindex не заменяет авторизацию.
