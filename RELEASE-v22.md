# MuratovaLife v22 — убрать демонстрационные результаты

По запросу удалены все публичные демонстрационные блоки результатов на странице профориентации:
- рекламный баннер «Результаты в цветных диаграммах»;
- ссылка «Посмотреть пример результатов» и демонстрационные карточки с выдуманными баллами;
- ссылки на демонстрационный PDF и изображение отчёта в разделе «О программе».

Пять тестов остаются без изменений. Персональные диаграммы и кнопка PDF показываются **только после прохождения хотя бы одного теста**, исключительно для реально полученных результатов. Непройденные тесты больше не заполняются примерами. Результаты по-прежнему хранятся только в локальном браузере, а не на сервере.

Содержимое админ-панели, данные, опубликованные статьи и изображения, вопросы тестов и обработчики CMS не менялись. Существующие ресурсы на диске сохранены; публичные ссылки на образец удалены.

Перед деплоем: резервная копия постоянного тома `/app/data`; не удалять Docker volume, не менять `CMS_DATA_DIR`. Архив не содержит содержимое серверного тома.
